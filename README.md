# Calculatrice .NET MAUI

Activité n°4 - Atelier de développement mobile.
Calculatrice mobile en .NET MAUI (Grid, Border, VerticalStackLayout, HorizontalStackLayout, ScrollView), adaptée au portrait et au paysage.

Auteur : ATANGANA AYISSI NESTOR - ENSP Douala

Lancer : ouvrir `Calculatrice.csproj` dans Visual Studio (charge de travail .NET MAUI), choisir Windows Machine ou un émulateur Android, puis exécuter.
